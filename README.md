# vinted-manager
Vinted Manager è un’applicazione canvas sviluppata con Microsoft Power Apps per organizzare e tenere traccia degli articoli messi in vendita su Vinted. Permette di avere sotto controllo in un unico posto cosa è in vendita, cosa è stato venduto e i relativi dettagli.

L’interfaccia segue uno stile Soft glass (effetto vetro, trasparenze morbide) ottenuto esclusivamente con i controlli nativi di Power Apps, senza ricorrere al controllo HTML.
